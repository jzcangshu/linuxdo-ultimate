# V0.3.2 State Hardening Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修复 v0.3 大改遗留的重复启动、导航失联、标签状态错乱、多浏览器页面恢复竞争、资源回收和预览兼容问题。

**Architecture:** 顶层脚本是唯一完整入口，内嵌页只由父页在加载后安装一次轻量桥，并在样式就绪前保持隐藏。标签数组是唯一顺序来源，活跃时间只服务页面池淘汰；浏览器标签页会话彼此独立，跨访问恢复只领取最后关闭的一份，同一标签页暂时离站再返回仍沿用自身状态。消息以真实来源窗口和主题身份校验，拦截导航必须收到父页确认，否则恢复论坛原生导航。

**Tech Stack:** TypeScript、Vitest、jsdom、esbuild、Tampermonkey/Violentmonkey 用户脚本接口、Discourse 同源 iframe。
