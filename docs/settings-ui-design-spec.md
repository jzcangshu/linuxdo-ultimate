# 设置界面设计规格

本文只定义设置界面必须承载的内容、状态关系和行为，不限定具体视觉方案。设计应沿用 Linux Do 的主题颜色、字号变量和控件习惯。

## 全局结构

- 入口：论坛顶部导航条中的齿轮按钮。
- 标题：`Linux Do Ultimate`，其中 `Ultimate` 使用亮黄色强调。
- 内容分组：布局、阅读与标签、实用工具。
- 底部操作：恢复默认设置、检查更新、Github（代码仓库）、LDC 捐赠。
- 面板必须适配亮色与暗色主题，不使用内部滚动；较矮视口通过压缩间距保持完整内容可达。
- 所有设置修改后立即生效并自动保存，不设置“保存”按钮。
- 所有开关使用复选框或切换控件；枚举使用下拉框或分段控件；数量使用滑杆并常态显示当前数字。
- 设置名称、控件和辅助文字必须在同一视觉行或同一对齐网格中，不能出现标签与下拉框上下错位。

## 布局

### 启用分屏模式

- 类型：开关。
- 默认：开启。
- 作用：控制分屏阅读和页内帖子标签功能。
- 关闭时隐藏“帖子详情页位置”“帖子标签栏样式”及其从属项、“下次访问时恢复上次打开的帖子”“按分类为帖子标签上色”和“最多保留活动页面”。
- 关闭后论坛恢复原生页面布局；脚本本身仍运行，设置入口和其他实用工具仍可使用。

### 帖子详情页位置

- 类型：单选枚举。
- 默认：自动。
- 选项：自动、右侧、中间。
- 依赖：仅在“启用分屏模式”开启时显示。
- 自动模式由可用横向空间决定详情页位于右侧还是中间。

## 阅读与标签

### 帖子标签栏样式

- 类型：分段单选枚举，视觉与“帖子详情页位置”一致。
- 默认：横向。
- 选项：横向、垂直。
- 依赖：仅在“启用分屏模式”开启时显示。
- 垂直样式为每个阅读区创建独立标签侧栏，不改变标签归属或会话数据。

### 自动收起垂直标签栏

- 类型：开关。
- 默认：开启。
- 依赖：仅在选择垂直标签栏时显示。
- 收起时只显示帖子图标和分类标记；悬停、键盘聚焦、拖拽或右键菜单打开时覆盖当前阅读区展开，不挤压正文。

### 按帖子分区自动分组

- 类型：开关。
- 默认：关闭。
- 依赖：仅在选择垂直标签栏时显示。
- 仅使用内置主分类常量表分组，不读取页面样式、不新增网络请求；无法识别的帖子进入“其他”。

### 下次访问时恢复上次打开的帖子

- 类型：开关。
- 默认：关闭。
- 依赖：仅在“启用分屏模式”开启时显示。
- 作用：控制关闭浏览器标签页后，下次进入论坛是否恢复最近一次帖子标签和列表状态。
- 当前浏览器标签页内的普通刷新始终恢复当前状态，不受此开关影响。

### 隐藏话题列表中的用户头像列

- 类型：开关。
- 默认：开启。
- 作用：隐藏话题列表中参与讨论用户头像列，为标题和阅读区腾出横向空间。

### 按分类为帖子标签上色

- 类型：开关。
- 默认：开启。
- 依赖：仅在“启用分屏模式”开启时显示。
- 作用：使用帖子所属分类的图标颜色，为标签添加半透明背景。
- 关闭后仅移除标签背景颜色；固定分类常量仍可供可选的垂直分组使用，活动标签继续保留清晰高亮。

### 最多保留活动页面

- 类型：滑杆加数字。
- 默认：3。
- 范围：1 至 10。
- 依赖：仅在“启用分屏模式”开启时显示。
- 作用：限制同时保留在内存中的帖子页面数量，不限制帖子标签总数。
- 超出数量时暂停最久未使用的非活动页面，重新打开时恢复页面和滚动位置。

## 实用工具

### 启用链接悬浮预览

- 类型：开关。
- 默认：关闭。
- 作用：允许在当前页面内预览链接。
- 开启时显示“预览触发”和安全提示。
- 安全提示文案：`预览页面会运行目标网站脚本，请只预览可信链接。`
- 安全提示应作为紧邻开关名称的红色小号辅助文字，不单独占据整行或卡片。

### 预览触发

- 类型：单选枚举。
- 默认：双击。
- 选项：双击、单击。
- 依赖：仅在“启用链接悬浮预览”开启时显示。
- 控件必须与左侧名称在同一行垂直居中。

### 在顶部显示 LDC 收入

- 类型：开关。
- 默认：开启。
- 作用：在顶部导航条语言切换按钮旁显示 LDC 收入值，点击该值可刷新。

## 底部操作

### 恢复默认设置

- 类型：次要按钮。
- 作用：立即恢复全部默认设置并应用。
- 与外部链接操作区分层显示，避免误触。

### Github（代码仓库）

- 类型：外部链接按钮。
- 地址：`https://github.com/jzcangshu/linuxdo-ultimate`。
- 在新浏览器标签页打开。

### LDC 捐赠

- 类型：菜单按钮，与 Github（代码仓库）按钮并排。
- 点击后展开 1、5、10 LDC 三个额度。
- 选择额度后在新浏览器标签页打开对应支付页面，并自动收起菜单。
- 按 Esc（退出键）或点击面板外部时关闭菜单。

## 标签栏显示规则

- 标签宽度根据标签栏可用宽度等分收缩，不能固定为统一像素宽度后过早产生横向滚动条。
- 标签宽度仍需保持一致，使连续点击关闭按钮时按钮位置稳定。
- 单个标签设置合理最大宽度，标签较少时不应无限拉伸。
- 标题使用站内较小字号，过长时单行省略，关闭按钮始终可见；不提供固定按钮。
- 标签之间保留约 3 像素的背景间隙，使相同分类颜色的相邻标签仍能清楚分隔。
- 只有活动标签显示底部高亮条，非活动标签不显示高亮条。
- 横向与垂直标签都支持鼠标中键关闭，并复用同一套右键菜单和标签状态。
- 垂直标签按高度排列，拖拽使用纵向避让；启用分类分组后只调整同一主分类内的顺序。
