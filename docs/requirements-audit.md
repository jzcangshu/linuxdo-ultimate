## 2026-08-05 全面复核结论

此前 11 项分屏硬化与后续缺陷均已有实现和回归测试。本轮使用已安装的 0.1.10 在真实论坛只读验证了以下场景：

| 场景 | 结果 |
| --- | --- |
| 首页、分类、用户活动、书签、搜索 | 可保留或进入分屏，帖子从原列表位置打开 |
| 直接帖子入口 | 首次直达保持原生阅读；主动点击下一站内帖子后才以主页为列表建立分屏，并保留前后两帖 |
| 侧栏跨分类与收起 | 不关闭分屏；收起前后列表比例约 39.03%，保持不变 |
| 多标签生命周期 | 新增标签时 iframe（内嵌页面）同步增加；关闭后同步释放；每个阅读区仅显示其当前活动标签，其他标签保留在内存中并可即时切换 |
| 列表增量加载 | 30 条增至 60 条，继续等待 7 秒仍为 60 条，没有无限加载 |
| 阅读区站内帖子链接 | 外层地址和布局不变，新帖子作为新阅读标签打开 |
| 阅读区图片 | 保持论坛灯箱，不创建链接预览 |
| 阅读区站外链接 | 成功打开带样式的静态预览；转到新标签后预览自动关闭 |
| 二屏列表滚动条 | 位于列表右边缘而非浏览器窗口最右侧 |
| 设置条件显隐 | 关闭分屏或预览后，对应的详情位置或触发方式选项隐藏，重新开启后恢复 |
| 控制台 | 未发现脚本自身异常；测试工具自身统计请求偶发超时与论坛脚本无关 |

本轮额外发现并修复：关闭“下次访问恢复”时，同一浏览器标签页刷新也可能丢失当前标签；同时开启该选项缺少真正的最近会话入口。0.1.11 已将当前标签页刷新恢复与跨访问恢复分开，并增加整页启动回归测试。

分类颜色标注和会话修复属于 0.1.11，不能用已安装的 0.1.10 做真实页面结论；目前已通过自动化验证，安装新版后仍需做一次实站截图和刷新验收。

## 已完成修复

| 优先级 | 问题 | 已确认原因 | 验收要求 |
| --- | --- | --- | --- |
| 高 | 帖子内容页滚动几次后自动刷新 | Discourse（论坛系统）滚动时会更新当前帖子楼层 URL（网址）；内嵌页面把该变化上报给父页后，父页又把新 URL 写回 iframe（内嵌页面）的 `src`，造成重新加载循环。阅读计数请求本身不会刷新页面 | 已分离页面上报地址和显式导航地址；单元测试确认楼层地址变化不再重设 `src` |
| 中 | 帖子阅读页滚动条未延伸到窗口底部 | Discourse（论坛系统）的全局 iframe（内嵌页面）规则带有 `1000px` 最大高度；脚本设置了 `height: 100%`（高度占满）却未解除该上限，因此高于 1000px 的阅读面板会在底部留下空白 | 对帖子 iframe（内嵌页面）明确设置 `max-height: none`（取消最大高度）；真实页测得阅读容器与活动 iframe（内嵌页面）同为 1158px、底部间隙为 0，并增加回归测试 |
| 中 | 内嵌帖子右侧时间轴控件消失 | 脚本为扩大正文宽度，明确隐藏了 `.topic-timeline`（帖子时间轴）、`.timeline-container`（时间轴容器）和 `.topic-navigation`（帖子导航） | 已恢复阅读模式、日期、进度和底部操作；热门回复独占一行，回复与通知在下一行并排 |
| 高 | 帖子列表触底后无限增量加载并卡死页面 | 脚本把 `#main-outlet`（帖子列表容器）改成独立滚动区，同时把页面文档固定为一屏；Discourse（论坛系统）的增量加载仍按页面滚动高度判断，首次触底后会一直判定处于页底 | 列表恢复使用论坛原生页面滚动；阅读区和侧边栏改为粘性定位；真实分类页由 30 条触底加载至 60 条，等待 5 秒未继续增长；列表滚动位置改为记录和恢复页面滚动位置 |
| 高 | 分屏帖子正文中的链接无法触发预览 | 预览控制器只安装在顶层页面，帖子正文位于独立 iframe（内嵌页面），其点击事件不会冒泡到父页；双击模式下第一次单击还可能先被论坛外链确认接管 | 内嵌页按父页配置拦截单击或双击，将经过校验的网址和坐标发给父页统一预览；消息必须来自已管理的帖子 iframe（内嵌页面）；顶部栏和侧边栏导航不再触发预览 |
| 高 | 分屏阅读区内的站内帖子链接覆盖当前阅读标签 | 父页面的帖子链接监听器无法收到 iframe（内嵌页面）内的点击，内嵌论坛路由因此直接在当前 iframe（内嵌页面）导航 | 点击另一个站内帖子时由内嵌页向父页发送新标签请求；同一帖楼层链接及带 Ctrl（控制键）等修饰键的点击保留原生行为；父页只接受受管理 iframe（内嵌页面）的请求 |
| 中 | 链接预览窗口不能移动，打开新标签后仍残留 | 预览标题栏没有拖动交互，新标签链接也未通知预览控制器清理窗口 | 标题栏支持鼠标和触控拖动并限制在视窗内；点击“在新标签页打开”保留原生导航，同时自动关闭预览 |
| 高 | 帖子图片被预览为乱码，普通网页只显示文本 | 阅读区桥接抢先拦截论坛图片灯箱；跨域响应未检查内容类型；清理器删除了网页全部外部、内嵌及行内样式 | 帖子图片点击交还论坛灯箱；按响应头区分网页、图片和不支持内容；沙箱内保留 CSS（样式），继续移除脚本、表单、嵌套框架及事件处理器 |
| 中 | 二屏模式列表滚动条在浏览器最右侧 | 为避免论坛增量加载死循环，列表使用页面原生滚动，根滚动条的固定位置因此与列表边缘不一致 | 二屏模式隐藏根滚动条，改用与页面滚动同步的列表边缘滚动条；支持拖动、点击轨道和键盘操作，论坛原生滚动及增量加载逻辑不变 |
| 中 | 独立 Credit（积分）脚本会在列表页和帖子 iframe（内嵌页面）重复显示 | 原脚本匹配所有 Linux Do（社区）页面，不区分顶层页面与内嵌帖子 | 保留原有两接口差值计算、5 分钟刷新、点击刷新、提示明细和带凭据请求；仅由顶层应用在语言切换旁挂载一次，并提供设置开关 |
| 低 | 设置面板层级单薄且缺少项目与捐赠入口 | 原面板是无分组的紧凑控件列表，长标签与操作区缺少稳定布局 | 使用社区主题与字体变量实现 Material 3（材料设计第三版）式分组、焦点和按压反馈；底部并排提供 Github（代码仓库）与 LDC捐赠，捐赠菜单明确列出 1/5/10 LDC 三个新标签页支付入口 |
