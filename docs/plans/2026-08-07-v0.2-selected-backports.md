# V0.2 Selected Backports Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 以 `v0.2.0` 为唯一基线，只回迁用户指定的 11 项功能与修复，发布一个不包含 `V0.3` 架构改动的后续版本。

**Architecture:** 保留 `V0.2` 的顶层应用、列表 iframe、阅读 iframe 和现有页面桥接结构。所有改动限定在分类数据来源、标签交互、会话持久化、预览权限和有界缓存维护；不引入新的页面运行时、导航确认协议或启动流程。

**Tech Stack:** TypeScript、Vitest、jsdom、esbuild、Tampermonkey/Violentmonkey 用户脚本接口、Discourse 同源 iframe。

### Task 4: 会话隔离、刷新与存储一致性

**Files:**
- Modify: `src/core/defaults.ts`
- Modify: `src/core/storage.ts`
- Modify: `src/app.ts`
- Modify: `src/main.ts`
- Test: `tests/storage.test.ts`
- Test: `tests/app-refresh-startup.test.ts`
- Test: `tests/app-session-startup.test.ts`

**Steps:**
1. 添加失败测试：浏览器标签页各自持有会话；刷新只复用自身；跨访问只领取最后关闭的一份；刷新或暂时站内整页跳转产生的候选快照会被当前会话撤销。
2. 将“可恢复快照”保存为带关闭时间的小型队列，读取时只领取最后关闭且不属于当前页面的一份，绝不合并标签集合。
3. 保留当前 `sessionStorage` 会话编号；用短租约避免复制标签页共用同一编号。
4. `UserscriptStorage` 在实例创建时固定一个后端；后端失败只报告，不在同一生命周期混读另一份旧数据。
5. 运行存储和启动测试。
