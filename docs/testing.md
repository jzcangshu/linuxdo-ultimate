# 测试说明

## 自动化检查

在项目根目录运行：

```powershell
pnpm test
pnpm check
pnpm build:all
```

测试覆盖设置和会话恢复、路由识别、标签状态、内嵌页面生命周期、布局断点、阅读计数请求顺序、站外内容清理，以及整页打开与设置恢复流程。

更新检查测试必须覆盖语义版本比较、清单地址校验、24 小时成功缓存、手动绕过缓存、更新清单与项目版本同步，以及新版本状态同时标记顶部设置按钮和底部检查更新按钮。自动检查不得在无更新或失败时弹出菜单。

插件构建测试还会确认 host、bridge 和 preview runtime 物理分离：host 与 bridge 不得包含上游预览窗口源码，bridge 不得包含顶层应用，manifest（清单）必须只将 host 注入顶层、将 bridge 注入子 iframe。Chrome 与 Firefox 发布包还必须分别包含正确的后台声明、Linux Do Ultimate 产品名、官方 Logo 的四种尺寸及位于压缩包根目录的清单。

## 本地界面夹具

启动本地服务器：

```powershell
node scripts/serve-fixtures.mjs
```

打开 `http://127.0.0.1:4173/latest`，点击“测试打开帖子”。验证矩阵：

| 视口 | 预期模式 | 关键检查 |
| --- | --- | --- |
| 1920×1080 | 三分屏 | 侧栏、正文、列表顺序正确，无横向溢出 |
| 1440×900 | 二分屏 | 列表在左、正文在右，无横向溢出 |
| 1100×800 | 二分屏临界值 | 正文与列表按 65:35 自动收缩，无横向溢出 |
| 1099×800 | 原生 | 分屏面板隐藏，页面恢复普通滚动 |

默认设置下，刷新当前浏览器标签页应恢复标签、活动帖子、列表网址、滚动位置和布局；关闭该标签页后重新访问论坛则不恢复。开启“下次访问时恢复上次打开的帖子”后，只应载入最后关闭的一个浏览器标签页会话，多个窗口的帖子不得合并，刷新仍打开的页面也不得领取其他页面的关闭记录。收起侧栏后正文与列表应保持当前比例。关闭分屏后，顶部 logo（标志）条设置入口仍须可见，并可重新开启分屏。

拖动帖子标签时，拖动图像应跟随指针，相邻标签应在跨越中心位置时平滑避让，放下前不得改写会话顺序；取消拖动后所有临时位移必须清除。多级分类帖子应使用固定色表中的主分类颜色，页面徽标或元数据中的自定义颜色不得覆盖常量。

## 插件安装与实站只读检查

先在 `chrome://extensions` 中加载 `dist/extension`，并关闭旧用户脚本。Firefox 使用 `about:debugging#/runtime/this-firefox` 临时载入 `dist/extension-firefox/manifest.json`。使用已登录的浏览器检查 `/latest`、`/search`、`/bookmarks`、分类页、用户页和直接帖子地址。只验证容器、侧栏、主题链接、参与者列、正文和时间线结构；不发帖、不点赞，也不手动调用阅读计数接口。

安装后应验证首次直接打开帖子保持原生页面，从该帖点击另一帖子后才进入分屏并保留前后两帖；同时验证同源帖子交互、恢复开关、新内嵌页面预览和控制台错误。不要通过开发工具手动重放阅读计数请求。

## 预览兼容性回归

站外预览必须验证：

- 预览 iframe（内嵌页面）不含 sandbox（沙箱）属性，目标脚本和表单可运行。
- 相对脚本、样式、图片和 `srcset`（响应式图片地址）会解析到目标站地址。
- 图片链接仍进入图片查看器，不得被当成网页源码显示。
- 关闭预览或关闭功能后，未完成请求、临时 iframe（内嵌页面）和过期缓存会释放。
