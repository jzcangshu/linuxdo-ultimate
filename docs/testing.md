# 测试说明

## 自动化检查

在项目根目录运行：

```powershell
pnpm test
pnpm check
pnpm build
```

测试覆盖设置和会话恢复、路由识别、标签状态、内嵌页面生命周期、布局断点、阅读计数请求顺序、站外内容清理，以及整页打开与设置恢复流程。

## 本地界面夹具

启动本地服务器：

```powershell
node scripts/serve-fixtures.mjs
```

打开 `http://127.0.0.1:4173/latest`，点击“测试打开帖子”。验证矩阵：

| 视口 | 预期模式 | 关键检查 |
| --- | --- | --- |
| 1920×1080 | 三分屏 | 侧栏、正文、列表顺序正确，无横向溢出 |
| 1440×900 | 二分屏 | 列表在左、正文在右，无横向溢出 |
| 1100×800 | 二分屏临界值 | 正文与列表按 65:35 自动收缩，无横向溢出 |
| 1099×800 | 原生 | 分屏面板隐藏，页面恢复普通滚动 |

默认设置下，刷新当前浏览器标签页应恢复标签、活动帖子、列表网址、滚动位置和布局；关闭该标签页后重新访问论坛则不恢复。开启“下次访问时恢复上次打开的帖子”后，只应载入最后关闭的一个浏览器标签页会话，多个窗口的帖子不得合并，刷新仍打开的页面也不得领取其他页面的关闭记录。收起侧栏后正文与列表应保持当前比例。关闭分屏后，顶部 logo（标志）条设置入口仍须可见，并可重新开启分屏。

## 实站只读检查

使用已登录的 Chrome（谷歌浏览器）检查 `/latest`、`/search`、`/bookmarks`、分类页、用户页和直接帖子地址。只验证容器、侧栏、主题链接、参与者列、正文和时间线结构；不发帖、不点赞，也不手动调用阅读计数接口。

安装后应验证首次直接打开帖子保持原生页面，从该帖点击另一帖子后才进入分屏并保留前后两帖；同时验证同源帖子交互、恢复开关、新内嵌页面预览和控制台错误。不要通过开发工具手动重放阅读计数请求。

## 安全回归

站外清理测试必须证明以下内容不能进入预览：

- `script`（脚本）、`iframe`（内嵌页面）、表单和媒体执行容器
- `onclick` 等事件属性
- `javascript:` 等危险协议
- `srcset`、内联样式、令牌和完整性属性

链接与图片必须解析为绝对 HTTP（超文本传输协议）或 HTTPS（安全超文本传输协议）网址，链接强制使用新标签和 `noopener noreferrer`（隔离来源窗口）属性。
