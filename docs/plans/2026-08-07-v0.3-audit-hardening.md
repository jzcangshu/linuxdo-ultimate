# V0.3 Audit Hardening Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修复除窄宽分屏策略以外的全部审计问题，降低长期存储、网络、脚本解析和内嵌页面资源成本，并让自动化测试覆盖真实运行实现。

**Architecture:** 顶层用户脚本改为唯一运行入口，并由父页面向同源内嵌页面安装轻量桥接，避免每个页面重复解析完整程序。帖子页面池共享一个全局活动额度；持久状态和活动运行时彻底分离，所有长期存储建立有界索引和过期回收。预览仍保留完整脚本权限，但改为按需安装、可卸载，并补齐重定向、大文件和下载链接防护。

**Tech Stack:** TypeScript、Vitest、jsdom、esbuild、Tampermonkey/Violentmonkey 用户脚本接口、Discourse 同源 iframe。
