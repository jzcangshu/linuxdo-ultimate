# Linux Do Ultimate

一个面向 Linux Do 的浏览器插件，用分屏阅读、页内帖子标签和实用工具减少来回切换页面的操作，同时尽量保留社区原有的界面与使用习惯。

## 核心功能

- **分屏阅读**：帖子详情页可显示在列表右侧或中间。非阅读页与帖子正文分别独立加载，一侧导航或刷新不会清空另一侧。直接访问某个帖子时保持论坛原生页面；当前页再打开其他站内页面时才进入分屏，没有上级列表时使用论坛主页。
- **页内多帖标签**：在同一浏览器标签页中打开、切换、关闭和拖动排序多个帖子；横向与垂直两种标签栏可自由切换，均支持鼠标中键关闭。垂直标签栏可自动收起并在悬停时覆盖展开，也可按内置主分类自动分组。标签可选按主分类上色，最多可同时保留 10 个活动阅读页面。
- **标签右键管理**：右键帖子标签可将它移动到新的并排阅读区、在浏览器新标签页打开、重新加载、复制链接、把整篇主题添加到社区书签，或关闭同一阅读区中的其他标签。任一阅读区关空后自动消失，剩余阅读区直接扩充并保留已加载页面。
- **自适应布局**：宽屏自动分配侧栏、帖子正文和话题列表；正文与列表默认按 65:35 分配，可拖动调整，比例会自动保存。
- **按需恢复**：刷新当前浏览器标签页会同时恢复非阅读页位置和正在阅读的帖子；默认不会在关闭后下次访问时重新打开它们。主动开启恢复后，也只恢复最后关闭的一个浏览器标签页中的阅读状态。
- **阅读计数修复**：在分屏阅读时补充社区所需的阅读记录流程，避免帖子阅读未被正确计入。
- **帖子阅读小工具**：可选启用“只看楼主”，可与社区的热门回复筛选叠加使用，并按主题记住状态。
- **极简模式**：可分别隐藏全局公告、分类徽章、话题标签和列表头像，减少页面干扰。
- **低端设备性能优化**：可选减少动画与过渡效果，降低低端设备的渲染负担。
- **错误弹窗自动过盾**：检测到社区的 403、429 或响应失效弹窗后，自动进入 Challenge 页面并返回原地址。分屏模式下只恢复发生错误的列表或帖子区域，不会清空其他已打开的阅读页。
- **链接悬浮预览**：直接采用 Link Hover Previewer 4.13.1 的预览窗口、动态加载、多标签、前进后退、最大化、书签、图片查看、缓存和位置记忆能力，并保留统一图标、鼠标刷新按钮及打开新标签后自动关闭。悬停不会预先请求内容，只有实际触发预览后才开始加载。
- **LDC 收入**：在顶部语言切换按钮旁显示收入参考值，点击可刷新。
- **更新检查**：设置页可手动检查新版本；插件也会低频静默检查仓库内的结构化更新清单，发现新版时以亮黄色呼吸效果提醒，不会自动下载安装。

## 安装与设置

### Chrome（谷歌浏览器）

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择项目中的 `dist/extension` 目录。
4. 刷新 Linux Do，点击顶部导航栏中的齿轮按钮进行设置。

当前构建包为 `dist/linuxdo-ultimate-v0.6.9-chrome.zip`，解压后按同样方式加载其目录。

### Firefox（火狐浏览器）

1. 打开 `about:debugging#/runtime/this-firefox`。
2. 点击“临时载入附加组件”，选择项目中 `dist/extension-firefox/manifest.json`。
3. 刷新 Linux Do，点击顶部导航栏中的齿轮按钮进行设置。

当前构建包为 `dist/linuxdo-ultimate-v0.6.9-firefox.zip`，要求 Firefox 140 或更高版本。Chrome 与 Firefox 共用同一套业务源码，只在浏览器清单和构建目标上保留必要差异。

扩展在浏览器管理页中统一显示为 `Linux Do Ultimate`，并使用 Linux Do 官方圆形 Logo。安装插件前必须关闭旧版 Linux Do Ultimate 用户脚本，二者同时运行会重复创建界面和拦截链接。若已安装其他链接预览、页面布局或自动过盾脚本，也建议关闭它们在 `linux.do` 上的运行权限，避免重复处理同一页面事件。

设置中可调整分屏开关、详情页位置、横向或垂直标签栏、垂直栏自动收起和分类分组、是否恢复上次帖子、活动页面数量、只看楼主、极简模式及其隐藏项、低端设备优化、链接预览方式及 LDC 收入显示。插件本身的启停由浏览器扩展管理页控制。

`dist/linuxdo-ultimate.user.js` 继续作为 V0.2 兼容产物保留，用于回归和必要时回退，不再是 V0.4 的推荐安装方式。

## 隐私与权限

设置、分屏比例和阅读标签仅保存在 Linux Do 对应的浏览器本地存储中，插件不会收集或上传用户数据。插件申请全部站点访问权限仅用于用户主动触发的站外链接预览；预览默认关闭，关闭时不会加载预览核心，也不会请求目标网站。为了复现动态网页，预览会运行目标网站脚本，使用则代表接受风险。

浏览器插件无法读取 Tampermonkey（油猴）的私有脚本存储，因此从 V0.2 用户脚本首次迁移时，需要重新确认一次设置；论坛账号和站内数据不受影响。
