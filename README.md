# Linux Do 社区终极优化脚本

一个面向 Linux Do 的用户脚本，用分屏阅读、页内帖子标签和实用工具减少来回切换页面的操作，同时尽量保留社区原有的界面与使用习惯。

## 核心功能

- **分屏阅读**：帖子详情页可显示在列表右侧或中间。直接访问某个帖子时保持论坛原生页面；当前页再打开其他站内页面时才进入分屏，没有上级列表时使用论坛主页。
- **页内多帖标签**：在同一浏览器标签页中打开、切换和关闭多个帖子；标签宽度会随可用空间等分收缩，可选按分类上色，当前页以底部高亮条标识，最多可同时保留 10 个活动阅读页面。
- **自适应布局**：宽屏自动分配侧栏、帖子正文和话题列表；正文与列表默认按 65:35 分配，可拖动调整，比例会自动保存。
- **按需恢复**：刷新当前浏览器标签页会保留正在阅读的帖子；默认不会在关闭后下次访问时重新打开它们。主动开启恢复后，也只恢复最后关闭的一个浏览器标签页中的阅读状态。
- **阅读计数修复**：在分屏阅读时补充社区所需的阅读记录流程，避免帖子阅读未被正确计入。
- **链接悬浮预览**：直接采用 Link Hover Previewer 4.12.2 的预览窗口、动态加载、多标签、前进后退、最大化、书签、图片查看、缓存和位置记忆能力，并补充 Linux Do 内容安全策略兼容、鼠标刷新按钮及打开新标签后自动关闭。
- **LDC 收入**：在顶部语言切换按钮旁显示收入参考值，点击可刷新。
- **紧凑话题列表**：可隐藏话题列表中的用户头像列，为正文和标题留出更多横向空间。

## 安装与设置

1. 安装 Tampermonkey（油猴）或 Violentmonkey（暴力猴）。
2. 安装 `dist/linuxdo-ultimate.user.js`。
3. 刷新 Linux Do，点击顶部导航栏中的齿轮按钮进行设置。

若已安装其他链接预览或页面布局脚本，建议先关闭它们在 `linux.do` 上的运行权限，避免重复拦截。

设置中可调整分屏开关、详情页位置、是否恢复上次帖子、活动页面数量、话题列表头像列、链接预览方式及 LDC 收入显示。脚本本身的启停直接由用户脚本管理器控制。

## 隐私与权限

设置、分屏比例和阅读标签仅保存在本地。脚本不会收集或上传用户数据。站外链接预览仅在用户主动触发时请求目标网页。为了复现动态网页，预览会运行目标网站脚本，因此只应预览可信链接。
